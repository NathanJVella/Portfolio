This is a project I started working on which is inspired by Robocraft's building system. Growing up, this was my all-time favourite game to play and when the developers stopped actively working on the game, there was no other game that could replace it.

I wanted to make a similar system with my own tweaks. This started off as a proof of concept years ago, but I had so much more planned for this and would like to eventually incorporate this system into a proper game setting.
In its current state, it features 3 different modes:
- Build Mode: Able to scroll through a list of different part types and add them to an existing surface using LMB. Before placing a part, a ghost object of the part will appear so you have an idea of what and how it will be placed. Clicking RMB removes the target part. Scroll Wheel controls the rotation / orintation of the object.
- Paint Mode: Able to pre-select a material and whichever part you click on will change its material to the selected one.
- Test Mode: Combine all the parts into a single gameobject and assign a rigidbody to test its functions and physics similar to how it would react and behave in a proper game setting.
