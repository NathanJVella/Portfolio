Cricket 26 - The Official Game of the Ashes

20 Nov, 2025

Cricket 26 was the beginning and turning point for all future titles server-side. Many new changes and upgrades started in Cricket 26 and would later be backported to older / legacy titles and this would be the one branched off for newer titles.

The first new addition was implementing Redis (specifically Valkey), to utilise AWS ElastiCache and benefit from quicker read speeds and shorter lived data to reduce database load and speed up many read-heavy endpoints. The second was to replace AWS Eventbridge schedulers with Hangfire. Next was to replace in some cases our custom mutexLocks and db locks with a key-value lock short-lived in memory (using Redis).
