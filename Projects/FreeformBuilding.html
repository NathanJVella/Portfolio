Freeform Building

This is a project I started working on which is inspired by Robocraft's robot building system. Growing up, My favourite game to play was Robocraft and when the devs stopped actively working on the game, there was no other game I could replace it with, with the same type of game it was. 

I wanted to make a similar system with my own tweaks. This is still a work in progress and still have a lot more planned to add and polish up but this is its current state:
- ​3 Modes:
- Build Mode
- Colour Mode
- Test Mode
